Research

Questions about enhancer activity, cellular context, assay reliability, and regulatory grammar.

01 / First project

Measured activity across cellular contexts

Compare the same DNA constructs in HepG2, K562, and WTC11 cells to understand shared and selective reporter activity.

The matched lentiMPRA library offers a controlled starting point. Construct identities, biological replicates, barcode coverage, and normalization must reconcile before we interpret differences. The library was selected partly using earlier activity measurements, so its proportions describe that selected library rather than all genomic DNA.

The working question

Among jointly assayed constructs, which activity patterns are consistent across cells, and which are selective for a measured context?

Our first deliverable is a documented activity table and a reproduction of a selected published comparison. Cell specificity was already analyzed in the original study; an extension needs its own feasibility and novelty assessment.

02 / A possible extension

How reliable is the activity evidence?

For regions with adequate K562 measurements in multiple assays, investigate whether activity calls remain stable under defensible coverage, orientation, and overlap criteria. A region absent from an active-call list may be untested or insufficiently measured.

A possible extension asks whether selective and broadly active constructs differ in the stability of their K562 evidence. Shared source measurements must be identified, and the number of independently measured overlapping loci must support the comparison.

Read the cross-assay study →

03 / A mechanistic alternative

Motif combinations and cell state

Synthetic MPRA experiments provide designed changes to motif identity and arrangement. The hematopoiesis collection offers a route to studying combinations that behave differently across cell states, with explicit sequence designs and controls.

This branch requires its own R-data import, definition of the activity scale, and matched comparison of synthetic constructs. It is a promising alternative if cross-assay overlap does not support a useful extension.
