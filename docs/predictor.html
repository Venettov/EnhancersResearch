Our iEnhancer-2L reconstruction

From a DNA sequence to a prediction

Paste your sequences or choose a FASTA file. The saved model predicts non-enhancer, weak enhancer, or strong enhancer for each 200-base fragment.

↳Runs on your device

Your input stays in your browser. The model downloads when you run your first prediction; sequences are not uploaded or stored by this tool.

01 Add your sequences

FASTA format: a >identifier line followed by DNA. Each sequence must have exactly 200 A/C/G/T bases. Lowercase letters and wrapped lines are accepted. Up to 1,000 sequences and 1 MiB per run.

What this tool tells you

This is our implementation of iEnhancer-2L, using the primary models trained on 13 October 2026. Its labels describe the historical enhancer benchmark. Predictions do not establish activity in HepG2, K562, WTC11, or another cell type. The original authors’ server can return different labels.

The browser computes each prediction from the saved model weights. The example results are used only for comparison after prediction. Sequences longer or shorter than 200 bases are rejected; choose and document any genomic windows before submitting them.

Try the authors’ iEnhancer-2L tool

Open the authors’ tool ↗

The web server accompanying the original paper uses two prediction layers: first, enhancer versus non-enhancer; then, strong versus weak for sequences predicted to be enhancers.

  1. Paste sequences in FASTA format or upload a FASTA file. Their Example link shows sample input; email is optional. View a FASTA example · Download example (.fasta)
  2. Click Submit to run the prediction and view the results.
  3. Use Download on the results page to save the output.

Their ReadMe guide illustrates overlapping 200-base windows for a longer input. To compare with our predictor, submit the same 200-base sequences to both tools. You can download our original 200-sequence comparison set.

The authors’ tool opens in a new tab. Submitting there sends your sequences to their server. Our comparison above uses their saved responses from 19 October 2026.

FASTA input example

Copy the entire block, including the line starting with >, or download the file to upload it to either predictor.

>probe_0001
CCTTCTGAGATAGATACTGTTATTCTCATTCACAGATGTGGACCCTGAGA
CCAGGGAGGTTGCGTGGCATCATTACATCAGAAGGGGAGTGGTCTGAATC
CACTCCTCCCCTTCCAGGGCAGGAAGTCAACAGAGAAGGGCTCTGTGGTA
ACGTTGACAATCACAAATCAGTGGCATAAACATCTCCTTAAGACATGCAG
  • The first line is the identifier. The > symbol starts each sequence; you can replace probe_0001 with your own name.
  • The sequence below the identifier contains 200 A/C/G/T bases in total. Line breaks do not change the sequence.
  • To add another sequence, start a new >identifier line and put its bases underneath.

This is probe_0001 from our 200-sequence comparison set.
