Original collection

Original papers and their corresponding data

The original sequences and supplements used to reconstruct iEnhancer-2L, with related materials from the other papers supplied by Prof. Dehzangi.

iEnhancer-2L introduced the shared benchmark; EnhancerPred and iEnhancer-EL reuse it. The inspected MCSE snapshot contains the same training and test sequences as our files. These are chromatin-annotation labels, not cell-specific reporter measurements.

Data files and analysis code are different resources. The original sequence files are available; our iEnhancer-2L scripts are a reconstruction of the paper. Complete author training code has not been located for iEnhancer-2L, EnhancerPred, or iEnhancer-EL in the reviewed materials. Data, code, published results, and sources → · iEnhancer-2L setup and commands →

Authors’ web tool: the Liu Lab iEnhancer-2L prediction server ↗ is available and was used for our prediction comparisons. It has usage instructions ↗ and original data ↗. The tool provides labels; it does not supply the complete author training workflow. Tool documentation →

Archived materials: MCSE has public notebooks with documented defects; our repaired results and the unrun VISTA plan are preserved in the MCSE archive. Its candidate fragments are not a verified independent evaluation set for iEnhancer-2L.

Present locally does not mean ready for every analysis

The full recheck covers 51,069,049,058 bytes: 55 reference-checksum matches, 5 accepted-publication receipt matches, and 49 recorded-size matches with new local hashes. Size-only checks do not establish upstream byte identity. A fresh clone does not contain the downloaded datasets or model weights.

The downloader still rejects five receipt-backed publication copies against historical expectations, and the archived DNABERT prediction launcher calls a missing Python file. The lentiMPRA specificity population is recovered, but score reproduction is unresolved. The findings and their analysis consequences establish the current limits on resource use.

02ENCODE lentiMPRAFunctional measurements54 resources
0.804 GB

Processed files for eight experiments, including the three joint-library experiments from Agarwal, Inoue et al. (Nature, 2025), plus design and activity tables.

Research use

Planned comparison of fixed iEnhancer-2L scores with measured activity in HepG2, K562, and WTC11. These cells were chosen because the study tested the same DNA library in all three.

Interpretation

Use the combined TSV or the three replicate TSVs per experiment, not both. Barcode coverage recovers 55,977 specificity-table names; the numerical scores remain unreproduced and two control aliases need original FASTA confirmation.

Provenance is part of the analysis

The research repository contains source manifests and download scripts. The website presents the collection’s structure and interpretation; the four original PDFs and small benchmark files are tracked in Git, while the newer downloads and model weights are retrieved from their source hosts.

Before combining datasets

Dataset integration requires compatible species and genome assemblies, preserved cell/assay/replicate/construct identities, and a distinction between active, adequately measured inactive, insufficiently measured, and untested observations. The analysis design describes the proposed comparison.
