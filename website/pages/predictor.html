What this tool tells you

This is our implementation of iEnhancer-2L, using the primary models trained on 13 October 2026. Its labels describe the historical enhancer benchmark. Predictions do not establish activity in HepG2, K562, WTC11, or another cell type. The original authors’ server can return different labels.

The browser computes each prediction from the saved model weights. The example results are used only for comparison after prediction. Sequences longer or shorter than 200 bases are rejected; choose and document any genomic windows before submitting them.
