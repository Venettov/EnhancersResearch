# AlphaGenome / AlphaGenome Atlas (2026)

The model paper, Atlas preprint, supplements, and research code snapshot are in `PAPERS/`, `SUPPLEMENTARY/`, and `CODE/`. The complete Atlas is roughly one petabyte, so it is not a practical bulk download. Check the [official downloads portal](https://alphagenome.google/downloads) for available data artifacts and the [official API repository](https://github.com/google-deepmind/alphagenome) for programmatic access and current terms.

- AlphaGenome paper: https://doi.org/10.1038/s41586-025-10014-0
- AlphaGenome Atlas preprint: https://doi.org/10.64898/2026.09.16.26363192
- API and code: https://github.com/google-deepmind/alphagenome
- Research code: https://github.com/google-deepmind/alphagenome_research
